# Hi, I'm Vee

Crypto builder. I build small, verifiable tools: on-chain verification, airdrop tracking, and contracts that grade work instead of trusting it.

## Projects

- [WorkProof](https://github.com/0xsters/genlayer-workproof-verifier) - a GenLayer Intelligent Contract that grades submitted work against written acceptance criteria, with the verdict decided by validator consensus.
- [WorkProof App](https://github.com/0xsters/genlayer-workproof-app) - the web frontend for the WorkProof Verifier contract.
- [PageWitness](https://github.com/0xsters/genlayer-pagewitness) - a GenLayer Intelligent Contract that answers questions about what a public web page actually says, backed by a verbatim quote from the page.
- [genlayer-verify-cli](https://github.com/0xsters/genlayer-verify-cli) - inspect a deployed GenLayer Intelligent Contract from the command line: code hash, schema, and methods.
- [Dropfolio](https://github.com/0xsters/dropfolio) - portfolio and airdrop tracker for EVM chains and Solana: native and token balances, USD values, and outgoing transaction counts.
